# vps-status

Public heartbeat JSON (status.json) for the rigplane VPS lane. Updated every
5 minutes by bot-monitor.sh. Fields: gateway state, OpenClaw version, uptime,
disk percent, load, per-job last runs — the same data the public
glm-vps-status page shows. Nothing private lives here.
